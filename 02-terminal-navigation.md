In this assignment, I learned basic terminal commands to manage files and folders. Commands like `pwd` and `ls` help me check my current location and view files. I used `mkdir` to create folders, `cd` to navigate between folders, and `touch` to create files. I also learned to copy, rename, delete, and display files using commands like `cp`, `mv`, `rm`, and `cat`. This practice helped me understand file management and how to open a project in VS Code using `code .`.
